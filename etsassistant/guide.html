使用说明

附使用说明如下。此仓库也可 git 到本地进行其他探究，但必须遵循其许可证。
  1. 以管理员身份运行本程序（避免 PyAutoGUI 点击失败）。
  2. 将系统默认录音设备设为「立体声混音」（控制面板 → 声音 → 录制）。
  3. 打开 E听说 进入跟读作业界面，窗口不被遮挡、单显示器。
  4. 在「模板管理」页依次截取四个按钮图片（播放原文 / 开始录音 / 停止录音 / 下一个）。
  5. 回到「自动跟读」页点击「开始」。

更详细的环境准备与命令请见 快速开始 页面。

本页面为模板占位，正式发布前可补充截图与更细致的操作指引。

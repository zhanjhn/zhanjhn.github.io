使用须知

使用本软件默认已知晓并同意以下使用须知。请务必先阅读 使用说明 与 隐私协议。

1. 适用与禁止

  • 本软件仅供个人技术探索与学习使用。
  • 严禁在任何正式考试、测验、测评或商业环境中使用本软件及其任何功能。
  • 请在使用本软件时保持应有的英语听说练习，软件不能替代真实学习。

2. 使用前准备

  1. 以管理员身份运行本程序，避免自动化点击失败。
  2. 将系统默认录音设备设为「立体声混音」（控制面板 → 声音 → 录制）。
  3. 打开 E听说 进入跟读作业界面，确保窗口不被遮挡、使用单显示器。
  4. 在「模板管理」页依次截取四个按钮图片（播放原文 / 开始录音 / 停止录音 / 下一个）。
  5. 回到「自动跟读」页点击「开始」。

3. 高级功能风险

  • DLL 一键编译 / 部署：属于实验性、高风险模块，会修改 E听说 安装目录、可能触发杀软拦截，并违反软件许可协议。默认不编译、不部署，须您自行评估并在理解风险后显式操作。
  • 操作前请备份相关数据；如造成环境异常，请使用卸载功能或手动删除对应文件恢复。

4. 合规要求

您须遵守所在国家/地区的法律法规、学校与考试机构的纪律要求，以及 E听说 软件自身的许可协议。因违规使用导致的一切后果由您自行承担。

5. 版本与更新

本软件可能不定期更新。更新内容以项目 Release 页面 为准。继续使用即视为接受更新后的须知与协议。

⚠️ 核心提醒

英语听说非常重要，请保持应有的练习；本软件仅限个人探索使用，禁止用于考试等场景。
